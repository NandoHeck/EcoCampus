# Screenshots

Adicione aqui os prints da aplicação para o README principal.

Sugestão de conjunto mínimo:

- `landing.png` — Landing page (hero + benefícios)
- `dashboard.png` — Dashboard logado (stats + destaques)
- `detail.png` — Detalhe de anúncio
- `create.png` — Formulário "Publicar anúncio"
- `mobile.png` — Mobile 375px com bottom-nav
- `pwa-install.png` — Modal de instalação do navegador
- `offline.png` — Fallback offline
- `lighthouse-pwa.png` — Aba PWA do Lighthouse com pontuação verde

Como tirar:
1. `npm start`
2. Abra em resolução alvo (desktop: 1440x900; mobile: DevTools 375x812).
3. Chrome DevTools → tecla `Ctrl+Shift+P` → digite "screenshot" → "Capture full size screenshot".
4. Salve nesta pasta e referencie no README principal.
